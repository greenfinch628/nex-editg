# Repository workflow

Read CONTRIBUTING.md before changing this repository. Record future changes in
CHANGELOG.md with an ISO 8601 UTC timestamp and a short categorized description.
GitHub origin/main is authoritative; gitea is the backup mirror. Use main for
installation and keep published commits, release tags, packaging, and release
artifacts synchronized to both hosts; verify both before reporting done. Delete
merged feature branches from both hosts when their work is complete.
Do not push custom changes to an upstream remote.
